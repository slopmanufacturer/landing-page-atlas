01 / The instrument

No screen.
No presets.
No undo.

The HYDRA-6 is built in a small workshop in Sheffield from through-hole parts, anodised aluminium, and a stubborn belief that an instrument should be learnable in an afternoon and interesting for a decade.

Each voice has two oscillators, a 24 dB/octave ladder filter that self-oscillates, two ADSR envelopes, and an LFO. There is no menu. If you want a different sound, move a knob. If you want the same sound again, remember it.
