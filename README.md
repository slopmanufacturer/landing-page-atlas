Landing Page Atlas is a collection of landing pages you can open, read, copy,
and change. Every page is a folder with its own HTML, CSS, and JavaScript.
There is no build step, no package manager, and no shared stylesheet.

The live gallery is branded **HTM / Designs**. The repository is Landing Page
Atlas.

## Start here

- **Browse the catalogue:** [slopmanufacturer.github.io/landing-page-atlas](https://slopmanufacturer.github.io/landing-page-atlas/) — filter by family, open any page, copy the HTML from the card.
- **Read the FAQ:** [the FAQ on the live site](https://slopmanufacturer.github.io/landing-page-atlas/#faq) — build steps, reuse, licensing.
- **Use this template:** [github.com/slopmanufacturer/landing-page-atlas/generate](https://github.com/slopmanufacturer/landing-page-atlas/generate)
- **Using an AI agent?** Point it at [AGENTS.md](AGENTS.md) before it touches the repository.
- **Clone it:**

```sh
git clone https://github.com/slopmanufacturer/landing-page-atlas.git
cd landing-page-atlas
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## What you get

- 42 complete landing pages, each with its own layout, type, palette, and interaction.
- Seven distinct directions: newspaper, satellite console, perfume house, riso festival, tea room, synth datasheet, and a climbing gym.
- No frameworks, bundlers, analytics, cookies, or third-party scripts.
- Responsive layouts tested at 1440, 768, 390, and 320 px.
- Keyboard-operable controls, labelled forms, and `prefers-reduced-motion` support.
- Google Fonts with system fallbacks. The pages still work if the fonts do not load.
- A gallery page with a filterable catalogue, one-click source copy, quick start, and FAQ.
- MIT licence. Personal, commercial, modification, redistribution: all fine.

## How to use one page

1. Open the folder you want under `designs/`.
2. Copy `index.html`, `style.css`, and `script.js` into your project.
3. Change the CSS variables, the fonts, and the copy.
4. Delete anything you do not need. There is no shared code to break.

The gallery is optional. Every design folder works on its own.

For a fuller guide — including what to remove when a page leaves the atlas —
see [AGENTS.md](AGENTS.md). It is written for AI coding agents but useful to
anyone.

## Checks

The pages have no runtime dependencies. The checker is a development tool; it
does not change what the designs need.

```sh
python3 tools/check_designs.py
```

The static pass verifies folder structure, gallery entries, thumbnails, HTML
basics, local links, form labels, button types, and JavaScript syntax. It
needs only Python 3.9+.

For the browser pass, install Selenium and make sure Firefox and geckodriver
are on your `PATH`:

```sh
python3 -m pip install selenium
python3 tools/check_designs.py --browser
```

It loads the gallery and all 42 pages at 1440, 768, 390, and 320 px, checks
for horizontal overflow and JavaScript errors, and confirms the gallery
filters.

## Why 42?

Seven families with six different problems is a better test of range than six
pages that all look the same. The brief for each page was different. The only
shared rule was that nothing should look like a template.

## A note on the fonts

The pages load Google Fonts. If you are offline, or the network blocks them,
the system fallbacks take over. Nothing breaks. If you want a fully
self-hosted build, download the font files and replace the `<link>` tags in
each page.
