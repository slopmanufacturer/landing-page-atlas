02 / What's inside

Everything is
in the folder.

No package.json. No node_modules. No build step. Forty-five folders across eight families, each with an index.html, a style.css, and a script.js. Open one in a browser and it works.

Quick start 
$ git clone https://github.com/slopmanufacturer/landing-page-atlas.git
$ cd landing-page-atlas
$ python3 -m http.server 8000

Then open localhost:8000. No npm, no install, no build.

03 / FAQ

Questions,
answered.

The practical things people ask before copying a folder. If something is missing, open an issue on GitHub.

01Do I need a build step?+

No. Open index.html directly, or serve the folder with any static server. There is no npm install, no bundler, no compile step, and no generated output to keep in sync.

02Can I use just one design?+

Yes. Each of the 45 folders under designs/ is self-contained. Copy the folder you want and ignore the rest; the gallery is optional.

03Are the pages responsive?+

Yes. The layouts were tested at 1440, 768, 390, and 320 px. Controls reflow, type scales, and nothing scrolls sideways.

04Do the pages use libraries or trackers?+

No. All behavior is vanilla JavaScript. Fonts load from Google Fonts with system fallbacks. There is no analytics, no cookies, and no third-party scripts.

05Can I change the colors, type, and copy?+

Yes. Every design has its own style.css and no shared stylesheet. Change the CSS variables or rewrite the rules; the pages are meant to be remixed.

06What are the eight families?+

Editorial, Interface, Luxury, Print, Minimal, Industrial, Sport, and Civic. Seven families have six pages; Civic has three. No two pages share a stylesheet.

07Is it accessible?+

The pages use semantic HTML, labelled forms, keyboard-operable controls, and prefers-reduced-motion. It is a solid starting point, not a WCAG certification.

08Can I deploy it?+

Yes. It is a static site. GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any bucket will serve it. There is no server-side code.

09What is the license?+

MIT. Use it for personal or commercial work, modify it, and ship it. Attribution is appreciated but not required.
